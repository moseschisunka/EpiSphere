# Controlled public-health pilot package

EpiSphere remains a pre-production pilot until the acceptance evidence below is
complete. A pilot owner must be named before any real data is enabled.

Required approvals:

- written scope and governance owner;
- data-sharing agreement and source inventory;
- privacy impact review and data classification;
- named diseases, reporting units, and response workflows;
- trained data officers and epidemiologists;
- incident, key-rotation, backup, and rollback contacts.

Use [pilot-acceptance-checklist.md](pilot-acceptance-checklist.md) to record
evidence weekly. Do not expand from a bounded partner or synthetic dataset to
national or multi-country use without a signed go/no-go review.
# Pilot materials

Use the [acceptance checklist](pilot-acceptance-checklist.md) to collect the
required evidence and the [controlled-pilot charter](controlled-pilot-charter-template.md)
